# MowgliKart

Local VR kart/arcade platform: a **Mac master app** controls up to **8 Pico headsets** (PUI 3 / Android 8.1) over the LAN.

- Start here: [`docs/MAC_QUICKSTART.md`](docs/MAC_QUICKSTART.md)
- Unity editor wiring / scene generation: [`docs/UNITY_EDITOR_WIRING.md`](docs/UNITY_EDITOR_WIRING.md)
- Stack: Unity 2020.3 LTS, PicoVR Unity SDK 2.8.12.1 (`Pvr_UnitySDK`), Mirror v96, Addressables 1.19.
- Tests and first-run checklist: [`docs/TESTING.md`](docs/TESTING.md)
- Headset preparation: [`docs/PICO_PROVISIONING.md`](docs/PICO_PROVISIONING.md)
